# FigurArte Talent Hub

Proyecto FigurArte.es — plataforma de captación, gestión y presentación de candidatos de casting (actores, modelos, figurantes) para FigurArte (Javier González-Santiago).

Este primer mensaje es solo de inicialización del proyecto. NO construyas todavía páginas, tablas ni lógica funcional — eso llegará paso a paso en mensajes posteriores.

Por ahora, limítate a:
1. Configurar el tema visual (Tailwind + shadcn/ui) con esta paleta de marca, reutilizada del proyecto hermano figurarte.app:
   - Rojo principal: #E03030
   - Charcoal (texto/fondo oscuro): #282828
   - Crema (fondo claro): #E8E8D8
   - Navy (acentos): #001058
   - Radios de borde casi rectos, nada de esquinas muy redondeadas
2. Dejar una página de inicio provisional muy simple (solo el nombre "FigurArte.es" centrado con la paleta aplicada), a la espera de que se construya la Home real en un paso posterior.

No añadas autenticación, base de datos ni ninguna tabla todavía.
